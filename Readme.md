# Login Authentication Project

## About the Project
This project is a simple login authentication website developed using HTML, CSS, and JavaScript.

## Features
- User registration
- User login
- Password validation
- Confirm password validation
- Duplicate email checking
- Login success dashboard
- Logout functionality
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage
- Session Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## Note
This is a learning project. It does not implement secure, production-ready authentication.
